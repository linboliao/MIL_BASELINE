# 前列腺 WSI 诊断模型 —— 整体实验规划

最后更新：2026-09-06

## 0. 背景与目标

### 0.1 项目背景：这是一篇被 desk reject 的稿子的重做
本项目此前已经产出过一版完整稿件（"Toward Stable and Clinically Deployable AI for
Histopathologic Diagnosis of Prostate Cancer"）：7个PFM×3个倍率×4种染色归一化的系统性
优化 + Stability-Prioritized Ensemble (SPE) 集成 + 三中心外部验证（301/YNZL/FJSL）+
六中心染色鲁棒性 + 人机对比 + YOLO病灶定位，用的就是这批数据。**该稿子 desk reject**，
编辑给出的理由：
1. **贡献点单薄，被认为是纯工程优化，缺乏机制性洞见**——PFM/倍率/染色选型+集成策略读起来
   像"调参调出最优配置"，没有回答"为什么"
2. **外部中心少、任务本身较简单（二分类，准确率普遍95%+封顶），很难做出统计显著的性能
   提升**——独立外部队列的无配对比较天生统计功效低，压不出置信的差异

中途 NAS 误操作删除了该项目的数据，当前从 MPP 校正、患者级去污染开始的所有工作都是围绕
**重做并加强这篇稿子**展开，不是另起一个新项目。这个背景决定了下面所有 Phase 的优先级
排序：核心策略是把主证据链从"独立外部队列上的准确率对比"（低功效、纯描述）换成
"配对染色panel + 留一中心/类型"（高功效、能解释机制），PFM/倍率/染色的优化结论保留但
降级为 Methods/补充材料，SPE 集成作为方法论贡献保留。

### 0.2 核心矛盾与应对
主队列（开发集）体量大，独立外部测试队列体量小（301: 147例，ynzl: 183例），小外部队列
无法稳定分辨 <5pp 的模型差异（Wilson 95% CI 半宽 ~4-5pp），这正是 desk reject 理由2的
根源。因此主线论证不能靠"在小外部集上比个 AUC"，必须换成主队列内部的高功效设计
（留一中心 / 留一样本类型 的决策门，配对染色panel），外部集降级为补充证据。

## 1. 数据基础（当前状态，已核实）

### 1.1 关键 bug 修复：MPP 校正
`create_patches_fp.py` 的 `--use_mp` 路径原先跳过了 MPP 标定，导致部分池子（尤其 301，40x）
和训练数据（20x）之间放大倍率不一致，是此前 301 外部测试崩掉、多个模型不稳定的根因。
现已修复（`adjust_size()`，TARGET_MPP=0.5），全部三个主池 + Panel A/B 的坐标均已用修正后的
逻辑重新提取。这是 Methods 里的一句"patch 按 0.5 μm/px 标定"，不构成论文贡献点，只是数据
正确性的前提。

### 1.2 患者级污染清理
三个独立污染源被发现并按患者级去重：
- 连续切片跨中心染色 panel（Panel A 6中心×60例 + Panel B 20例匿名单位），139 slides
- AI-vs-中级医生对比集中被重命名、可追溯回开发集的切片，52 slides
- 此前记录但从未真正执行剔除的 duplicate_slides.csv，44 slides
三者去重后并集：**178 slides / 70 patients**，患者级从 dev/internal_test 中剔除。
清洗后：dev 1922 slides / 1164 patients，internal_test 315 slides / 206 patients（原为
2222/1227、333/217）。划分本身（患者归属）可用同一 seed=42 的 `StratifiedGroupKFold`
逻辑对任意 PFM 重新生成一致的五折。

### 1.3 五折划分
`StratifiedGroupKFold(n_splits=5, seed=42)`，按 (label|center) 分层、患者分组，dev/internal_test
边界不重新随机化（避免破坏已有实验的可比性）。每个 PFM 一套独立五折 CSV（特征路径不同），
划分逻辑相同、可复现，目前只有 **CONCH** 已经跑通了这一整套（详见第3节）。

## 4. 整体实验设计 —— 围绕"修复两条 desk reject 理由"重新排序

设计原则：每个 Phase 明确标注它主要回应哪条 desk reject 理由（①贡献单薄/缺机制性洞见，
②外部中心少/任务简单/难出显著性），确保投入的每一份算力都在补稿子的短板，而不是重复
原稿已经做过的东西。

### Phase 0（已完成）
MPP 修正、患者级去污染、clean 五折方案确定、CONCH 全链路跑通（训练+内部测试+外部测试）。
这是让原稿的底层数据可信的前提工作，本身不是新贡献，但如果不做，重投的稿子经不起审稿人
反查（污染切片、倍率错位一旦被发现是硬伤）。

### Phase 1（回应②，决策门，立即可做）—— 下一步优先级最高
拿已经就绪的 5 个 PFM 特征，在 clean cohort 上做：
- **留一中心（leave-one-center-out）**：新昌 / 迈新 / 省立 各留一
- **留一样本类型（leave-one-type-out）**：CNB / RP / TURP 各留一

留一集普遍在几百量级，95% CI半宽可压到 ~2pp，比外部集（±4-5pp）更有功效，直接把原稿
"三个外部中心测出的准确率都很高"这种低信息量的证据，换成"模型对哪种shift更脆弱"这种
有统计功效、能定量比较的证据。同时决定论文主线叙事是"跨中心泛化"还是"跨样本类型泛化"。

#### Phase 1 结果（已完成，2026-09-08）

范围扩展为 5-center leave-one-out：新昌 / 省立 / 301 / 云南肿瘤(ynzl) 各留一（迈新样本量太小，
始终留在训练集、不作为留出目标），加上留一样本类型 CNB / RP / TURP，覆盖 CONCH / UNI2 /
mSTAR / GigaPath 四个 PFM，共 4×7=28 组结果（AB_MIL，patient-level 90/10 分train/val，clean cohort）。

**留一中心（macro_f1 / macro_auc）**

| 留出中心 | CONCH | UNI2 | mSTAR | GigaPath |
|---|---|---|---|---|
| 新昌 | 0.986 / 0.997 | 0.996 / 0.999 | 0.979 / 0.996 | 0.992 / 1.000 |
| 省立 | 0.879 / 0.957 | 0.915 / 0.969 | 0.868 / 0.950 | 0.898 / 0.955 |
| 301 | 0.912 / 0.972 | 0.801 / 0.990 | 0.830 / 0.992 | 0.767 / 0.983 |
| 云南肿瘤(ynzl) | 0.976 / 0.991 | 0.969 / 0.998 | 0.994 / 0.999 | 0.976 / 0.995 |

**留一类型（macro_f1 / macro_auc）**

| 留出类型 | CONCH | UNI2 | mSTAR | GigaPath |
|---|---|---|---|---|
| CNB | 0.926 / 0.987 | 0.965 / 0.998 | 0.986 / 0.999 | 0.965 / 0.994 |
| RP | 0.795 / 0.952 | 0.792 / 0.966 | 0.905 / 0.961 | 0.836 / 0.959 |
| TURP | 0.936 / 0.986 | 0.974 / 0.996 | 0.916 / 0.992 | 0.847 / 0.988 |

**决策门结论：**

1. 省立、301 是 4 个模型共同的"难"中心；新昌、ynzl 对所有模型都容易（macro_f1≥0.97）。
   301 上 backbone 差异最大（CONCH 0.912 最稳，UNI2/GigaPath 掉到 0.80/0.77）——是与骨干
   网络强相关的真实域偏移，比"外部集准确率都很高"更有信息量。
2. RP 是 4 个模型共同的弱势类型（0.79–0.91），CNB/TURP 对所有模型都相对容易（≥0.79，多数
   ≥0.90）——难易排序与 backbone 无关，具备机制性解释空间，不是单一模型的偶然表现。
3. **留一中心的性能跨度（0.77–1.00）明显大于留一类型的跨度（0.79–0.99）**，且更不稳定 ——
   支持"中心/域偏移是泛化差距的主要来源，而非样本类型"。**论文主线定为跨中心泛化**，
   Phase 2 的配对染色 panel（同样是跨中心设计）与此结论互相印证。
4. mSTAR 整体最稳健（两维度波动最小，最差点仍≥0.83 macro_f1）；CONCH 在最难的 301 中心上
   反而是四者中最好的——可作为讨论部分骨干选择的证据。

（原始结果表：`datasets/ProstateDiagnosis/DataAnalysis/leave_one_out_summary_{model}_5center.csv`；
训练日志/checkpoint：`result/ProstateDiagnosis/DataAnalysis/AB_MIL_{model}_leave_one_center_5center/`
与 `..._leave_one_type/`）


### Phase 2（回应②+①，配对染色一致性，Panel A/B）—— 与 Phase 1 同等优先级
把此前搁置的"连续切片跨中心染色 panel"从可行性分析升级为正式实验：
- 坐标已就绪，特征提取是纯推理，用已训练好的 CONCH（或 UNI2）五折模型直接跑
- 配对设计（同一份组织、不同中心染色）天然比独立队列比较统计功效高得多，
  Fleiss' kappa / McNemar 配对检验能在小样本（60-80例×6中心）上给出显著、可信的结论——
  直接对症②"任务简单、难出显著性"，因为配对设计的效应量估计不依赖"准确率本身要有多低"
- 同时做**机制性延伸**（对症①）：量化归一化前后各中心特征分布的域差异（如特征中心间
  MMD/距离），把"染色归一化有没有用"从准确率对比变成"归一化到底缩小了多少可测的域
  差异、这个缩小量和一致性提升是否相关"——这是原稿最缺的"为什么"

### Phase 3（回应①，机制性延伸，依托已有模块）
- **倍率的机制性解释**：不止报"10x和20x准确率差不多"，而是用已有的 YOLO 定位模块，
  比较模型在10x/20x下的注意力/定位是否落在同样的腺体结构区域——支持"诊断信号主要来自
  结构而非细胞核细节"这一假设，把倍率选型从工程权衡变成有生物学解释支撑的结论
- **PFM 选型的机制性解释**：不止报哪个PFM准确率最高，而是分析特征空间的肿瘤/正常
  可分性（如 silhouette score）、跨中心特征漂移幅度——把"H-optimus-1最好"变成
  "H-optimus-1的特征空间对域偏移更鲁棒"，同时结合 Phase 1 的留一结果看"准确率最高
  的PFM是否也是泛化最好的PFM"（如果不是，本身就是一个值得写的发现）
- 这些机制性分析都是在已有训练结果基础上做特征空间/注意力分析，**不需要额外的大规模
  训练**，性价比高

### Phase 4（主线泛化方法，依 Phase 1 结果展开）
- 若中心效应更大：跨中心域泛化方法比较（MixStyle / CENTERADV 等，**必须在clean五折上
  重跑**，之前所有此类结果基于污染划分，作废）
- 若类型效应更大：跨样本类型（CNB/RP/TURP）泛化方法比较
- 可顺带在 5 个已就绪 PFM 上跑一遍，获得"方法×PFM"的鲁棒性证据

### Phase 5（支线，锦上添花，视时间/资源）
- SPE（Stability-Prioritized Ensemble）：原稿的方法论贡献，clean数据上重新验证即可保留
- **公开数据集补充外部验证**：PANDA（~10,600 WSI，CNB，2中心）、TCGA-PRAD（~450，RP）、
  DiagSet-B、SICAPv2、AGGC22（CNB）——直接对症②"外部中心少"，但优先级低于 Phase 1/2
  （留一设计+配对panel的功效已经比加几个新外部集更高，公开数据集主要是锦上添花）
- 301 阈值标定（Youden index，预计提升macro_f1不改变结论）
- 人机对比：110例，23/30重命名切片已溯源剔除，7例仍未定位，需用户确认或剔除

### Phase 6（写作）
- Methods: MPP标定（一句话）、五折方案、PFM/倍率/染色选型（降级为方法学描述）
- Results 主线：Phase1决策门 + Phase2配对panel（高功效证据）→ Phase3机制性解释 →
  Phase4域泛化方法比较（多PFM鲁棒性）
- Results 支线：SPE集成、外部验证（301+ynzl+可能的公开数据集）、人机对比
- 讨论：直接回应两条 desk reject 理由——机制性洞见部分单独成段，统计功效设计的选择
  单独说明为什么换成留一+配对而不是加更多外部队列

## 4.5 文献调研：还有什么任务方向可以做（2026-09-06）

围绕两条 desk reject 理由检索了近期文献，找到几个可以直接落地、且有具体方法可参照的方向：

### A. 直接支撑机制性分析（对症①），有现成方法可抄
- **Hospital-Specific Bias in Patch-Based Pathology Models**（arXiv 2508.14779, 2025）——
  系统评估多个PFM在TCGA patch上的"医院特异性偏置"：用 t-SNE 可视化发现即使高性能PFM的
  embedding 也会按医院明显聚类，说明疾病无关的机构信号会泄漏进特征空间；并用一个轻量
  对抗适配器去除医院信号，disease分类精度基本不掉。**这个方法可以直接搬到 Panel A/B 上做**
  ——我们的配对数据（同一份组织、不同中心染色）比TCGA的"真实但混杂"域偏移更干净，
  可以做同样的 t-SNE-by-center 可视化 + 定量化域信号泄漏程度，比原稿"归一化前后准确率
  对比"有更强的机制性解释力。代码开源：github.com/MengRes/pfm_domain_bias
- **Domain Generalization in Computational Pathology: Survey and Guidelines**
  （ACM Computing Surveys）——权威综述，可用来把留一中心/类型+配对panel的设计，正式
  嵌入到"domain generalization"的标准框架/术语体系里，让审稿人一眼看出这不是随手调参，
  而是按DG标准范式做的系统性评估。

### B. 定位/对标最新 SOTA，回应"缺乏方法论新意"
- **FLEX**（Knowledge-Guided Adaptation of Pathology Foundation Models，*Nature
  Communications* 2025年12月，HKU-MedAI）——用视觉/文本知识引导的信息瓶颈，把"疾病相关
  特征"和"机构伪影"解耦，在16个任务、9900+张片子上验证，显著缩小"已见域 vs 未见域"的
  性能差距，同时做了人群公平性分析。这是目前这个方向的高影响力最新工作，建议至少作为
  Related Work 引用、定位我们的贡献在哪；如果时间允许，可以考虑把 FLEX 的思路（而不只是
  MixStyle/CENTERADV这类较老的域泛化方法）也纳入 Phase 4 的方法比较，直接对标当前SOTA
  比只跟自己老方法比更有说服力。GitHub: HKU-MedAI/FLEX

### C. 任务本身升级 —— 已排查，标签不支持，放弃
现有完整标签只有二分类（有癌/无癌），**没有肿瘤比例、没有 Gleason/ISUP 分级标注**。
Gleason分级、肿瘤比例回归这两条"任务升级"路径因此**不可行**——没有 ground truth 就没法
验证模型输出是否正确，强行做出来的回归值/分级结果经不起审稿人追问"这个标签哪来的、
准不准"，风险比收益大，放弃。

**降级替代方案：把已有的 YOLO 肿瘤检测方案当描述性协变量用，而不是新的监督任务**
YOLO 检测/定位模块（原稿里已经在25例微小病灶子集上验证过，Dice 0.7735 / IoU 0.7477，
这个子集是有真实标注的）可以在没有全队列真值标签的前提下，提供两类**不需要标签验证**
的机制性证据：
1. **误分类的解释性协变量**：用 YOLO 在全队列上跑出的（未经验证的）肿瘤区域估计，
   按估计病灶大小分组，看模型误分类是否集中在"估计病灶小"的病例——这是相关性分析，
   不要求 YOLO 估计本身绝对准确，只要求组间排序大致合理，风险远低于把它当回归标签用
2. **倍率机制性分析的锚点**：比较 YOLO 在 10x/20x 下检测框的空间一致性（IoU-across-
   magnification），支持"诊断信号主要来自结构、低倍率下依然能定位"这一论点——这个用法
   只需要"同一张图不同倍率下定位结果是否一致"，不涉及跟外部真值比较，同样不需要新标签

**建议**：A（t-SNE-by-center机制性分析）和上述 YOLO 协变量分析都可以和 Phase 2/3 合并
执行，不需要新增数据/标签，是当前性价比最高的机制性补强；B 主要是写作/定位层面的调整，
成本很低；C 已放弃，不再作为可行方向。

## 4.6 文献调研第二轮：分类性能 / 算法 / 大模型三个角度（2026-09-07）

### 分类性能角度 —— 从"准确率"转向"可靠性"，正好化解封顶效应
- **[Beyond accuracy: Quantifying the reliability of MIL for WSI classification](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC12680235/)**
  （2025）——直接指出MIL模型很少被评估"可靠性"，提出定量可靠性指标。这跟我们的处境高度
  契合：任务在95%+准确率封顶，继续卷准确率没有意义，但**校准（calibration）、不确定性
  量化（MC-dropout/深度集成）、可靠性**是几乎没被本项目做过的维度，而且天然能用上我们
  已有的"6个PFM×5折"资源（多模型/多折方差本身就是现成的不确定性来源，不需要额外训练）
- UAD-FM（*npj Digital Medicine*）的不确定性分解思路（epistemic/aleatoric）可以直接借鉴

### 算法角度 —— 优先选"slide级、不需要新标签"的域适应方法
- **[HASD: Hierarchical Adaptation for Pathology Slide-Level Domain-Shift](https://papers.miccai.org/miccai-2025/0402-Paper1963.html)**
  （MICCAI 2025）——现有大部分域适应方法是patch级，HASD明确做**slide级**：域对齐+
  slide级几何不变性正则+patch级注意力一致性正则。这跟我们"倍率注意力一致性"的机制性
  分析角度（4.5节）几乎是同一个思路，但HASD是一个正式发表的算法框架——可以直接借鉴或
  对标，把我们的机制性观察升级成一个可命名、可复现的算法贡献，而不是停留在描述性分析
- **测试时自适应（TTA）**——UAD-FM 用 do-intervention 做因果TTA，不需要目标域标签，
  部署时用未标注的外部/panel数据做自适应，这跟我们"跨中心/跨染色泛化"的叙事天然契合，
  且不需要额外标注

### 大模型角度 —— 已确认无原始报告文本，放弃
WSI-级视觉语言模型/报告生成是当前最热方向之一（[TITAN](https://www.nature.com/articles/s41591-025-03982-3)/*Nat Med*、
SlideChat、WSI-LLaVA、PathAlign，甚至有一篇专门做前列腺病理报告生成的
[native-language prostate pathology report generation](https://arxiv.org/html/2608.23143)），
但这条路依赖 WSI-报告文本配对数据。**已确认没有原始报告文本**，跟 Gleason/肿瘤比例
一样属于"没有可验证标签、强做风险大于收益"的类别，**放弃**，最多在 Related Work 里
提一句定位当前研究热点，不作为可执行方向。

**结论**：三个角度里，只有分类性能（可靠性/校准）和算法（HASD式slide级域适应/TTA）
是当前数据条件下真正可行的，且都**不需要额外数据/标注**，直接在现有"6PFM×5折"基础
设施上就能做，优先级提到 Phase 3。大模型/多模态方向因缺少报告文本和临床变量，本轮
排除。

## 4.7 方法设计：Panel-Supervised 染色/中心不变性正则化（PSIR）

不做新的通用MIL架构，而是在已验证的 AB_MIL 骨架上加一个由 Panel A/B 真实配对数据驱动
的正则项。核心思想：**不用合成染色增强，而是用真实的"同一组织、不同机构染色"配对数据
作为不变性训练信号**——这是目前检索范围内没见过的做法（合成增强的有，真实但混杂的域
适应有，真实配对当训练信号的没有），是撑起方法论贡献的关键差异点。

### 4.7.1 数据切分（避免污染，避免自证）
Panel A（6中心×60例）按**病例**切分成训练信号集和留出评估集（例如 5 折交叉：每折
80%病例做训练信号来源，20%留出纯做评估，5折轮转取平均，本身就是一个有统计功效的
配对设计）。**留出集在训练阶段完全不可见**，否则"用panel训练、又用panel证明有效"
会构成自证循环，站不住脚。Panel B（20例匿名单位）可全部作为独立的第二个留出验证集
（不参与任何训练），进一步验证方法的跨数据集泛化性。

### 4.7.2 两种实现方案

**方案A（推荐，简单、易验证、风险低）：两阶段——先学不变投影，再训分类器**
1. 阶段1：只用 Panel A 训练信号集，在 PFM 原始特征（如 CONCH 512维）之上加一个小的
   投影头（如2层MLP），用监督对比损失（SupCon）训练——同一病例跨中心的 bag-level
   embedding（AB_MIL 注意力池化后的slide表示）拉近，不同病例推开。这一步不涉及
   诊断标签，纯粹学"这个组织不管在哪个中心染色，representation都应该长得像"
2. 阶段2：冻结或微调这个投影头，在其输出之上用主队列（dev/internal_test）正常训练
   分类器（标准CE loss），流程和现有 AB_MIL 训练完全一样，只是输入特征多了一层
   不变性投影
3. 优点：两个目标解耦，出问题容易定位（先单独验证投影是否真的降低了跨中心embedding
   距离，再看分类性能有没有受影响），改动小，可以复用现有训练代码，只需要新增一个
   "投影头预训练"脚本

**方案B（更强但更复杂）：联合多任务训练**
每个训练step混合两种batch：主队列分类batch（CE loss）+ Panel训练信号batch（按病例
分组采样2-3个中心的slide，同时算CE loss用真实标签 + SupCon对比loss拉近同病例
跨中心embedding）。总loss = L_CE_主队列 + α·L_CE_panel + λ·L_supcon_panel。
优点是端到端联合优化可能效果更好，缺点是需要写专门的多源dataloader、调两个额外
超参数（α、λ），出问题时两个loss互相干扰不好排查。**建议先做方案A验证概念可行，
方案A有效果再考虑升级到方案B**。

### 4.7.3 评估协议（对应之前"先验证中心差异确实存在"的思路）
1. 先跑基线：现有已训练的 CONCH 5折模型，在 Panel A 留出集上测跨中心一致性
   （disagreement rate、flip rate、Fleiss kappa）——这一步已经在做（见4.7.4状态）
2. 训练 PSIR 版本，同样在 Panel A 留出集 + Panel B（完全独立）上测同样的指标，
   对比基线是否有统计显著的改善
3. 同时必须验证：主队列 internal_test / 外部测试（301/ynzl）性能没有因为加了这个
   正则项而下降——不变性正则化如果学得太激进可能损失判别信息，这是最主要的风险点，
   需要专门检查
4. 如果 Phase 1 的留一中心结果已经跑出来，也可以顺带看 PSIR 是否同时缩小了留一中心
   的掉点幅度（不只是panel上的一致性），这样一个方法就能同时回应"配对高功效证据"+
   "主队列留一验证"两条证据链，说服力更强

### 4.7.4 当前状态
Panel A/B 的 CONCH 特征提取正在跑（GPU0，已加限速避免占满显卡），跑完先做上面
评估协议的第1步（基线中心差异量化），确认差异真实存在且有意义后，再实现方案A的
两阶段训练。
